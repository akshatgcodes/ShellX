# Changelog

All notable changes to **ShellX** are documented here.

---

## [1.0.0] — 2026-10-18

### ✨ Added
- REPL with `cd`, `pwd` and `exit` builtins, and any external command through `fork` / `execvp`
- Ctrl+C stops the running command without killing the shell
- readline-based input with ↑ / ↓ history and line editing
- Persistent, timestamped history in `~/.shellx_history.txt`, recalled across sessions
- `#keyword` fuzzy history search that re-runs the newest match
- Next.js project page
